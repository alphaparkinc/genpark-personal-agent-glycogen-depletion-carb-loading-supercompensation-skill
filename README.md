## 🛠️ MCP Tools Exposed
- `calculate_supercompensation_carb_needs`: Calculate precision carbohydrate intake (g/kg/day) and total hydration requirements to maximize skeletal muscle glycogen stores prior to race day.
- `synthesize_low_fiber_meal_cadence`: Synthesize a low-residue, low-fiber 36-hour fueling plan to minimize gastrointestinal distress while hitting 9g CHO/kg.

## 🚀 Installation & Usage

```bash
python -m genpark_personal_agent_glycogen_depletion_carb_loading_supercompensation_skill.server --test
```
